## Dependency Updates

- `FirelyNetVersion`: `6.7.0` → `6.8.0`, bumping `Hl7.Fhir.Base` and `Hl7.Fhir.R4` for every package that consumes Firely .NET SDK types (`Hl7.Cql.Fhir`, `Hl7.Cql.Packaging`, `Hl7.Cql.Packager`) and for the demo projects. A consumer with its own direct reference to the Firely .NET SDK should move it to `6.8.0` as well. `Hl7.Fhir.Base` `6.8.0` has the same dependencies as `6.7.0`, so no other package version moves with it. No public API, generated C# output, or CQL evaluation result changes with it. The two behavior changes in `6.8.0` do not reach the CQL SDK: the runtime's FHIR-to-CQL date and time conversions do not read the fraction-digit count that `Hl7.Fhir.ElementModel.Types.DateTime` now keeps from parsing, and the SDK does not call the FHIRPath conversion functions, which now return empty or `false` for a complex type instead of throwing. (#1825)
