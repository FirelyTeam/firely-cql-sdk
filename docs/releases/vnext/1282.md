# PR #1282

- Upgraded `Fhir.Metrics` from `1.3.1` to `1.4.0` in `Cql.Runtime`, `Cql.Firely`, and `CoreTests`.
- Cross-unit quantity `Add`/`Subtract` now work with the default metric service and return results in the most granular input unit.
- Fixed quantity `Multiply` by scalar/unitless quantities to preserve the non-`"1"` unit.
- Fixed quantity comparisons used by `Between` to reject incompatible dimensions instead of comparing unrelated canonicalized values.
